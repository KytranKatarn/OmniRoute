## Async Batch Jobs (ADR-048/049/050)
- Background threads, return job_id immediately
- Duplicate prevention: `create_job()` checks running job with same type+module
- `_log_governance()` writes direct to DB (not iaae_routes — avoids Flask context in threads)

## DB Gotchas
- `agent_emotional_state` (SINGULAR) — no `relationship_strength`, use `stress_level`/`mood_intensity`
- `agent_identity` (not `agent_personalities`)
- `agent_activity_events` (not `agent_activity_log`)
- `has_embedding` — use `embedding IS NOT NULL`
- Agent names: DB=code names (Nexus), UI=human names (Jin Park) via `display_name`

## Blueprint Gotcha (ADR-021)
If module has `templates/` subdir, MUST set `template_folder="templates"` in Blueprint.

## KB Taxonomy (knowledge_base table — 25,874+ entries, 99%+ embedded)

### Knowledge Types (use the right type — search weights differ)

| Type | Weight | Use for | MCP call |
|------|--------|---------|----------|
| `mistake_learned` | **1.3×** | Errors, anti-patterns, lessons from failures | `store_memory(knowledge_type='mistake_learned')` |
| `vault_note` | **1.2×** | Docs, ADRs, roadmaps, architecture decisions | `store_memory(knowledge_type='vault_note')` |
| `code_snippet` | 1.0× | Reusable code patterns, reference implementations | `store_memory(knowledge_type='code_snippet')` |
| `github_file` | 1.0× | Ingested from GitHub repos (auto-indexed by agent loop) | Auto-generated |
| `conversation_memory` | 1.0× | MCP session context, recalled facts | Auto-generated by session_briefing |

**Always use `mistake_learned` for errors — the 1.3× weight means they surface first when searching.**

### importance_score

- Type: `DECIMAL(3,2)` | Range: 0.00–1.00 | Default: 0.85
- `mistake_learned` entries: typically 0.90–1.00 (critical mistakes get 1.0)
- `vault_note` entries: typically 0.80–0.95
- `github_file` entries: typically 0.70–0.80 (lower signal density)
- The column name is `importance_score` — NOT `importance`

### Searching the KB Effectively

```python
# By type (most targeted):
mcp__archie__search_knowledge(query="...", types=["mistake_learned"], limit=10)

# By category tag:
mcp__archie__search_knowledge(query="...", category="module_capability")

# Semantic search (requires embeddings — 99%+ covered):
mcp__archie__search_knowledge(query="natural language description")

# Mistakes only (shortcut):
mcp__archie__search_mistakes(query="...")

# Brief results (less context used):
mcp__archie__search_knowledge_brief(query="...")
```

### 62 Mistakes (High-Value Search)

The 62 `mistake_learned` entries are the most actionable KB content. Key clusters:
- **Infrastructure**: VPS path errors, Docker networking, hairpin NAT, Caddy issues
- **Dispatch**: direct Ollama calls, wrong import paths, bypassing DHQ
- **Auth/tiers**: owner tier reset bugs, service account confusion
- **DB**: wrong column names, missing psycopg2.Json() wrapper
- **Deploy**: missing `--build`, wrong container names, WTF path errors

Search with: `mcp__archie__search_mistakes(query="<area>")` before attempting any infra/dispatch/auth work.
