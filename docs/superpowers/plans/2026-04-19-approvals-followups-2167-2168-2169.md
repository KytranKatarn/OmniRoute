## #2167 design — async resume on bridge approve

**Problem:** Today, `_approve_bridge` flips `bridge_jobs.status='approved'` but no consumer re-dispatches the image generation.

**What the pending_approval row actually contains** (from `department_dispatcher.py:2006`):
- `job_type='image_generation'`, `module_source`, `agent_name`, `station_code`, `status='pending_approval'`
- `metadata` JSONB = `{target_host:'cloud', prompt, escalation:'paid_cloud', user_id, image_params}`

**Resume approach (async via agent_loop job):**
1. Web approve flips status `pending_approval → approved`. Returns immediately (no spinning). *(unchanged from current #2163 code — the job picks it up.)*
2. New job `resume_approved_bridge_jobs` runs every 30s in agent_loop. Selects `bridge_jobs WHERE status='approved' AND job_type='image_generation'`. For each row:
   - Flip status `approved → running`, set `updated_at=NOW()`.
   - Read `metadata` JSON. Walk providers via `external_providers.get_providers_with_capability('image_gen')`, pick first paid tier (`tier_position >= 5`).
   - Call `generate_media(provider_key, {type: 'image', prompt, params})`.
   - On success: `UPDATE bridge_jobs SET status='completed', description||=' [cloud: <path>]', updated_at=NOW(), completed_at=NOW() WHERE id=%s` and `_log_cloud_image_usage(provider, user_id, cost_usd)`.
   - On failure: `UPDATE bridge_jobs SET status='failed', error_message=%s, updated_at=NOW() WHERE id=%s`.
3. Idempotency: flipping to `running` before the cloud call prevents two workers from picking up the same row.

**Why async not sync:** image gen can take 10–30s. Keeping the web approve button synchronous would make the LCARS modal hang. Async also gives graceful failure handling without the user's click spinning on a network error.

**Why a new job, not reuse the dispatcher:** the dispatcher is called via `request_work()`, which does full classification + welfare checks + agent selection. We already know the agent (`agent_name` in the row) and the capability (image_gen). Going directly to `generate_media` is simpler and matches what the dispatcher would've done in `_escalate_image_to_cloud` Tier 2.

**Tests:** Mock `external_providers.generate_media` to return a success tuple + a failure tuple. Seed a pending→approved row, run the job function directly, assert status transitions.

**Scope boundary:** only `job_type='image_generation'` for now. Other job types with `pending_approval` status (none today) are ignored by the job. Add them in future follow-ups as dispatcher paths grow.

## #2168 design — COMs ↔ Approvals cross-link

**Problem:** A user sees "Escalation #12345" in the COMs feed. They want to click and jump to the matching approval row in the Approvals tab.

**Approach (frontend only):**
1. COMs feed rows with `category='escalation'` get a click handler. The handler:
   - Parses the approval ID from the title (`Escalation #<N>`).
   - Switches the tab (`document.querySelector('[data-tab="approvals"]').click()` or equivalent — depends on existing tab logic).
   - Waits one event-loop tick for the tab's auto-load to fire.
   - Looks for `#approval-<N>` in the approvals container. Scrolls it into view + highlights (brief amber pulse).
   - If not found (approval was resolved), inserts a gentle toast: "This approval has been resolved — see Recent History below."
2. Needs the Approvals card renderer to give each card a stable `id="approval-<N>"` where N is the numeric part of `autonomy:N` / `contractor:N` / `bridge:N`. That's one line of JS to add.

```python
def resume_approved_bridge_jobs():
    """Re-dispatch bridge_jobs rows approved via the web Approvals UI.

    Picks up rows where status='approved' AND job_type='image_generation',
    flips them to 'running' (atomic claim), then calls the paid cloud provider
    to actually generate the image. Updates status to 'completed' with the
    file path, or 'failed' with the error message.

    Only image_generation is supported today — that's the only dispatcher path
    that creates pending_approval rows (department_dispatcher._escalate_image_to_cloud).
    Other job_types will be added as new dispatcher paths land.
    """
    import json as _json
    from database import get_db_cursor

    with get_db_cursor() as (_, cur):
        cur.execute(
            """SELECT id, metadata, agent_name
               FROM bridge_jobs
               WHERE status = 'approved' AND job_type = 'image_generation'
               ORDER BY approved_at NULLS LAST, id
               LIMIT 10"""
        )
        rows = cur.fetchall()

    if not rows:
        return 0

    try:
        from ai_bridge import external_providers
    except Exception as e:
        logger.error("resume_approved_bridge_jobs: external_providers unavailable: %s", e)
        return 0

    processed = 0
    for row in rows:
        row = dict(row) if not isinstance(row, dict) else row
        job_id = row["id"]
        metadata = row.get("metadata") or {}
        if isinstance(metadata, str):
            try:
                metadata = _json.loads(metadata)
            except Exception:
                metadata = {}

        # Atomically claim: flip approved → running. If another worker beat us, skip.
        with get_db_cursor(commit=True) as (_, claim):
            claim.execute(
                """UPDATE bridge_jobs
                   SET status = 'running', updated_at = NOW()
                   WHERE id = %s AND status = 'approved'""",
                (job_id,),
            )
            if claim.rowcount == 0:
                continue  # someone else got it

        prompt = metadata.get("prompt", "")
        user_id = metadata.get("user_id")
        params = metadata.get("image_params") or {}

        try:
            providers = [
                p for p in external_providers.get_providers_with_capability("image_gen")
                if (p.get("tier_position") or 0) >= 5
            ]
            if not providers:
                raise RuntimeError("no paid image providers available")
            provider = providers[0]
            result = external_providers.generate_media(
                provider["provider_key"],
                {"type": "image", "prompt": prompt, "params": params},
            )
            if result and result.get("success"):
                file_path = result.get("file_path", "")
                with get_db_cursor(commit=True) as (_, done):
                    done.execute(
                        """UPDATE bridge_jobs
                           SET status = 'completed',
                               description = COALESCE(description, '') || ' [cloud: ' || %s || ']',
                               completed_steps = total_steps,
                               completed_at = NOW(),
                               updated_at = NOW()
                           WHERE id = %s""",
                        (file_path, job_id),
                    )
                # Log cloud usage for cost tracking
                try:
                    cost = float(result.get("cost_usd") or 0)
                    with get_db_cursor(commit=True) as (_, usage):
                        usage.execute(
                            """INSERT INTO cloud_model_usage
                               (model_name, provider, prompt_tokens, completion_tokens,
                                cost_usd, user_id, task_type, success)
                               VALUES (%s, %s, 0, 0, %s, %s, 'image_generation', TRUE)""",
                            (
                                f"{provider['provider_key']}_image",
                                provider["provider_key"],
                                cost,
                                user_id,
                            ),
                        )
                except Exception as log_err:
                    logger.debug("resume_approved_bridge_jobs: cloud_model_usage log failed: %s", log_err)
                processed += 1
            else:
                err = (result or {}).get("error", "unknown provider error")
                with get_db_cursor(commit=True) as (_, fail):
                    fail.execute(
                        """UPDATE bridge_jobs
                           SET status = 'failed', error_message = %s,
                               updated_at = NOW()
                           WHERE id = %s""",
                        (str(err)[:500], job_id),
                    )
        except Exception as exc:
            logger.warning("resume_approved_bridge_jobs: job %s failed: %s", job_id, exc)
            with get_db_cursor(commit=True) as (_, fail):
                fail.execute(
                    """UPDATE bridge_jobs
                       SET status = 'failed', error_message = %s,
                           updated_at = NOW()
                       WHERE id = %s""",
                    (str(exc)[:500], job_id),
                )

    return processed
```

```javascript
function _comsJumpToApproval(approvalNum) {
    // Switch to approvals tab.
    var approvalsTab = document.querySelector('[data-tab="approvals"]');
    if (approvalsTab) approvalsTab.click();

    setTimeout(function () {
        // Look for autonomy first (most common source of escalation messages),
        // then contractor, then bridge.
        var found = null;
        for (var _p of ['autonomy', 'contractor', 'bridge']) {
            found = document.getElementById('approval-card-' + _p + '-' + approvalNum);
            if (found) break;
        }
        if (found) {
            found.scrollIntoView({ behavior: 'smooth', block: 'center' });
            var orig = found.style.boxShadow;
            found.style.transition = 'box-shadow 0.6s';
            found.style.boxShadow = '0 0 0 3px rgba(251,191,36,0.7)';
            setTimeout(function () { found.style.boxShadow = orig; }, 1800);
        } else {
            var panel = document.getElementById('panel-approvals');
            if (!panel) return;
            var toast = document.createElement('div');
            toast.style.cssText = 'background:rgba(251,191,36,0.15);border-left:3px solid #fbbf24;color:#fbbf24;padding:10px 14px;border-radius:4px;margin:12px 0;font-size:0.85rem';
            toast.textContent = 'Approval #' + approvalNum + ' has been resolved. See Recent History below.';
            panel.prepend(toast);
            setTimeout(function () { toast.remove(); }, 6000);
        }
    }, 500);
}
```
