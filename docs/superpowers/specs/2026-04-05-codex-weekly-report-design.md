# C.O.D.E.X. Weekly Knowledge Report — Design Spec

**Date:** 2026-04-05
**Project:** #221 — Agent-Driven Knowledge Intelligence Phase 2
**Task:** #1637 — C.O.D.E.X. Weekly Knowledge Report
**Status:** Approved design, pending implementation

---

## Problem

Knowledge accumulates across projects but there's no periodic summary. Users must manually check each project's gaps panel to understand what changed. There's no way to see week-over-week trends or compare project health.

## Goals

1. **Weekly digest per project** — summarize knowledge activity, decisions, tasks, gap changes.
2. **Pure SQL aggregation** — no LLM dispatch needed. Fast, reliable, deterministic.
3. **Stored as vault_note** — searchable, linked to project, visible in Knowledge Gaps panel.
4. **Consciousness job** — runs weekly on Sunday 03:00 UTC, follows existing patterns.

---

## Report Content (per project)

| Section | Data Source | Query |
|---------|-----------|-------|
| New KB entries | `project_knowledge_links` + `knowledge_base` joined, `created_at > NOW() - 7 days` | Count by type |
| Decisions made | `project_decisions` where `created_at > NOW() - 7 days` | Count + titles |
| Tasks completed | `unified_tasks` where `status='completed'` and `updated_at > NOW() - 7 days` | Count + titles |
| Agent dispatches | `bridge_jobs` where `project_id` set and `created_at > NOW() - 7 days` | Count by agent |
| Gap completeness | `get_project_knowledge_gaps()` | Current % + gap list |

## Storage

| Field | Value |
|-------|-------|
| `title` | "Weekly Report: {project_name} — {YYYY-MM-DD}" |
| `content` | Markdown report (see template below) |
| `knowledge_type` | `vault_note` |
| `source_type` | `weekly_report` |
| `importance_score` | `0.65` (between auto-doc 0.60 and human 0.85) |
| `tags` | `[project_slug, "weekly-report", "codex"]` |
| `category` | project slug |

## Content Template

```markdown
# Weekly Knowledge Report: {project_name}
**Period:** {start_date} to {end_date} | **Generated by:** C.O.D.E.X.

## Knowledge Growth
- **{new_links} new entries linked** this week
{type_breakdown}

## Decisions ({decision_count})
{decision_list_or_none}

## Tasks Completed ({task_count})
{task_list_or_none}

## Agent Activity ({dispatch_count} dispatches)
{agent_breakdown_or_none}

## Current Health
- Completeness: **{completeness}%**
- Gaps: {gap_list_or_all_clear}

---
*Auto-generated by C.O.D.E.X. on {date}. Weekly digest — not scored toward completeness.*
```

## Anti-Feedback-Loop

Same rule as D.A.R.W.I.N. auto-docs: `source_type='weekly_report'` entries do NOT count toward vault_note gap score. The gap analysis already excludes `source_type='auto_documentation'` — extend to also exclude `weekly_report`.

## Cooldown

6-day cooldown per project (prevents duplicates if job triggers twice in a week). Check: any `knowledge_base` entry with `source_type='weekly_report'` and matching project slug tag in last 6 days.
