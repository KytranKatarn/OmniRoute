# DHQ System Alerts History

**Date:** 2026-05-13
**Tab:** Department HQ → Autonomy
**Pattern:** Dispatch History (dispatch-history.js)
**Data source:** `system_notifications` table (19,293 rows)

---

## Context

The Autonomy tab exposes scheduler jobs, autonomy config, and department job monitoring. System Alerts History adds a fourth section: a paginated, filterable timeline of all platform notifications generated by the autonomy loop, agents, and system services.

`system_alerts` was the originally intended table but is currently empty with no producer. `system_notifications` is the active table (19k rows, 5 types: warning/info/error/alert/success). This spec targets `system_notifications`.

## API

### `GET /tools/department-hq/api/alerts/history`

**Query params:**

| Param | Type | Default | Notes |
|-------|------|---------|-------|
| `type` | string | `all` | warning / info / error / alert / success / all |
| `priority` | string | `all` | normal / high / critical / all |
| `status` | string | `all` | all / unread / read |
| `q` | string | `""` | Full-text search on `title`, `message`, `source` |
| `from_date` | string | 7 days ago | ISO date `YYYY-MM-DD` |
| `to_date` | string | today | ISO date `YYYY-MM-DD` |
| `page` | int | 1 | 1-based |
| `limit` | int | 50 | Max 200 |

**Response:**

```json
{
  "stats": {
    "total": 847,
    "unread": 312,
    "errors_24h": 14,
    "warnings_24h": 203
  },
  "rows": [
    {
      "id": 19001,
      "type": "warning",
      "priority": "normal",
      "title": "Model load timeout",
      "message": "qwen2.5:7b did not load within 60s",
      "source": "model_dispatch_worker",
      "source_icon": "⚙️",
      "is_read": false,
      "telegram_forwarded": false,
      "grouped_count": 1,
      "related_action": null,
      "metadata": {},
      "created_at": "2026-05-13T14:32:11"
    }
  ],
  "page": 1,
  "pages": 17,
  "total": 847
}
```

**Implementation notes:**
- `admin_required` decorator
- `stats` always computed for the current filter window (not full table)
- `errors_24h` / `warnings_24h`: fixed 24h window regardless of date filter
- Full-text search uses `ILIKE '%q%'` across `title || ' ' || message || ' ' || source`
- `is_archived = false` filter always applied (archived notifications are suppressed)
- Query uses indexed `created_at` for date range — add `LIMIT/OFFSET` for pagination

## JS — `alerts-history.js`

IIFE, no dependencies, same shape as `dispatch-history.js`.

**Public API (called from `onclick` attrs in template):**

```
window.ahFetch(resetPage)   — main fetch + render
window.ahPage(delta)        — pagination ±1
window.ahReset()            — clear all filters, reload
window.ahDebounce()         — 400ms debounce for text input
window.ahInit()             — idempotent init, sets default dates, calls ahFetch
```

**Internal functions:**

```
_params()                   — build URLSearchParams from filter inputs
_renderStats(stats)         — fill 4 stat chips
_renderTable(rows)          — build table body HTML
_renderPagination(p,pages,total) — prev/next buttons + label
_typeBadge(type)            — returns colored span HTML
_priorityBadge(priority)    — returns badge span or '' for normal
_setDefaultDates()          — from = 7 days ago, to = today
ahToggleRow(id)             — expand/collapse detail row
```

**Type badge colors:**
| Type | Color |
|------|-------|
| error | `#ef4444` (red) |
| warning | `#f59e0b` (amber) |
| alert | `#f97316` (orange) |
| info | `#00e5ff` (cyan) |
| success | `#10b981` (green) |

**Table columns:** Time · Source icon + Source · Type badge · Priority badge · Title · Unread dot

**Expandable detail row** (toggled by clicking main row): full `message` text (if different from title), `metadata` JSON (pretty-printed if non-empty), `related_action`, `grouped_count` if > 1, telegram forwarded indicator.

## Out of Scope

- Writing to `system_alerts` table (no producer built here)
- Mark-as-read bulk actions (read state set by existing notification_service, not this component)
- Real-time push / SSE (poll-on-tab-open is sufficient; alerts aren't time-critical to display)
- Archived notifications (excluded via `is_archived = false`)
