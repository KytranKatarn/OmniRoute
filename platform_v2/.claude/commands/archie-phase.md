# A.R.C.H.I.E. Phase & Roadmap Status

Show current development phase and roadmap progress.

## Instructions

1. Query the Blueprint API: `curl -s http://localhost:3000/tools/blueprint/api/roadmap`
2. Parse and display:
   - Current active phase(s) and their completion percentage
   - Recently completed phases
   - Upcoming phases marked as "planned"
3. Also check `blueprint_tasks` for any in-progress tasks

Format as a clear roadmap summary showing what's done, in progress, and next.
