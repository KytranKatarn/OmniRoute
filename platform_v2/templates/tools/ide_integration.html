Quick Setup Guide

Cursor AI Integration

  1. Open Cursor Settings

    Go to Settings > Features > Rules for AI

  2. Add A.R.C.H.I.E. Context

    Add this rule to your project:

    You have access to A.R.C.H.I.E.'s knowledge base via MCP at:
{{ request.host_url }}tools/cursor-integration/mcp/manifest
  3. Configure MCP Server

    Add to your .cursor/mcp.json:

    {
  "servers": {
    "archie": {
      "url": "{{ request.host_url }}tools/cursor-integration/mcp/manifest"
    }
  }
}

OpenCode / VS Code Fork Integration

  1. Install Extension

    Install the A.R.C.H.I.E. Assistant extension from the marketplace (coming soon) or use the REST API directly.

  2. Configure Connection

    In your settings.json:

    {
  "archie.serverUrl": "{{ request.host_url }}tools/cursor-integration",
  "archie.features": {
    "completion": true,
    "diagnostics": true,
    "codeActions": true
  }
}

VS Code Integration

  1. REST API Integration

    Use the HTTP Client extension or a custom extension to connect:

    POST {{ request.host_url }}tools/cursor-integration/api/connect
Content-Type: application/json

{
  "ide_type": "vscode",
  "workspace_path": "${workspaceFolder}",
  "client_id": "vscode-${machineId}",
  "capabilities": ["completion", "diagnostics", "hover"]
}

MCP Protocol

A.R.C.H.I.E. supports the Model Context Protocol for AI assistants.

Available Tools

archie_complete Get AI-powered code completions
archie_explain Get code explanations
archie_fix Fix code issues automatically
