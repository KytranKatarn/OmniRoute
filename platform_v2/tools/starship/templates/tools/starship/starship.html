DEPLOY A STARSHIP NODE

Add a new compute node to your fleet. Give it a name, then follow the setup instructions to get it online.

SETUP INSTRUCTIONS

Your node is registered and waiting for connection.

  1. Download the starship node package
    DOWNLOAD PACKAGE
  2. Extract the package on the target machine
    tar -xzf archie-starship-node.tar.gz cd archie-node
  3. Save this config as config.json in the node directory
  4. Start the node with Docker
    docker compose -f docker-compose.node.yml up -d
  5. The node will automatically connect to Archie and appear in your fleet. An admin will approve it and assign models based on your hardware.

RESYNC NODE
