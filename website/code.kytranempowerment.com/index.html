Capabilities

Built for AI-First Development

●

Local LLM Inference

Run Ollama models locally with zero data leaving your machine. Supports qwen2.5-coder, phi3.5, and any model in your Ollama registry. GPU-aware routing included.

■

Hub Connected

Connect to your A.R.C.H.I.E. platform for RAG-powered context from 18,000+ knowledge base entries and real-time agent dispatch across the fleet.

▲

Agent Routing

128 specialized agents across 16 departments auto-selected for your task. From F.O.R.G.E. engineering to V.I.G.I.L. security — the right agent, every time.

◆

Go TUI

Bubble Tea terminal interface with full LCARS theme. WebSocket streaming, skill picker, session management — a complete dev environment in your terminal.

Installation

Up in 60 Seconds

terminal
1 # Install from PyPI
2 $ pip install archie-engine
3  
4 # Configure your Ollama host
5 $ export OLLAMA_HOST=http://localhost:11434
6 $ export ARCHIE_MODEL=qwen2.5-coder:7b
7  
8 # Launch
9 $ python3 -m archie_engine
